# Portfolio

Статичное desktop-портфолио по макету Paper.

## Как открыть

Откройте файл `dist/index.html` в браузере. Для локального сервера можно выполнить:

```bash
python3 -m http.server 8000 --directory dist
```

Затем перейдите на `http://localhost:8000`.

## Структура

- `dist/index.html` — содержание страницы;
- `dist/styles.css` — все стили;
- `dist/assets` — изображения, используемые на сайте;
- `source-assets` — исходные изображения из задания.

Страница рассчитана на desktop. Анимации и адаптивная версия намеренно не добавлены.
