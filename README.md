# Portfolio

Статичное desktop-портфолио по макету Paper.

## Как открыть

Откройте файл `dist/index.html` в браузере. Для локального сервера можно выполнить:

```bash
python3 -m http.server 8000 --directory dist
```

Затем перейдите на `http://localhost:8000`.

## Структура

- `dist/index.html` — содержание страницы;
- `dist/styles.css` — все стили;
- `dist/typography.js` — автоматический перенос коротких предлогов и союзов;
- `dist/assets` — изображения, используемые на сайте;
- `source-assets` — исходные изображения из задания.

Страница адаптирована для полноэкранных и узких desktop-окон шириной 640–1920 px. На узких окнах карточки перестраиваются, чтобы изображения и текст не обрезались. Отдельная мобильная версия и анимации пока не добавлены.

## Автоматическая публикация на Beget

Workflow `.github/workflows/deploy-beget.yml` автоматически загружает содержимое `dist` на Beget после каждого изменения этой папки в ветке `main`.

Для публикации нужен отдельный FTP-аккаунт Beget, ограниченный корневой директорией сайта. В GitHub Environment `production` должны быть настроены секреты:

- `BEGET_FTP_SERVER` — имя FTP-сервера из панели Beget;
- `BEGET_FTP_USERNAME` — логин отдельного FTP-аккаунта;
- `BEGET_FTP_PASSWORD` — пароль этого FTP-аккаунта.

Пароль нельзя добавлять в файлы проекта или отправлять в сообщения. После настройки секретов публикацию также можно запустить вручную на вкладке Actions → Deploy to Beget → Run workflow.
